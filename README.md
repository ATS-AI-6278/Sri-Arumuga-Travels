# Sri Arumuga Travels

Premium travel brand site for small-car / taxi journeys from **Srivilliputtur, Tamil Nadu** across India.

## Design

Warm linen + terracotta system (no dark casino gold, no 3D car). CSS atmosphere only.
Conversion: Call · WhatsApp · Enquiry (WhatsApp handoff).

## Scripts

```bash
bun install
bun run lint
bun run build
bun run dev   # http://localhost:5173 (0.0.0.0)
```
